# Security Policy

## Data model

DebtShark is intentionally local-only. It does not send entered loan, repayment, timeline, or case-workspace information to a server. Browser storage remains subject to the browser and device’s own security model, so users should avoid shared devices and export important records themselves.

## Reporting a vulnerability

Please use GitHub’s private vulnerability reporting for this repository. Do not put exploit details, personal information, financial data, or real account information in a public issue.

Include a clear description, affected file or feature, reproducible steps using non-sensitive test data, and the impact you observed. We will acknowledge valid reports and work toward a fix before public disclosure.

## Scope

Reports about client-side data exposure, unsafe exports, content injection, dependency compromise, or behavior that could make a user’s local data less safe are in scope. General questions about a specific debt situation are not security reports and cannot receive individualized legal or financial guidance.
